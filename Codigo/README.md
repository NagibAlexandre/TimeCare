# Código do Projeto

## ESP32

O código responsável pelo funcionamento da placa ESP32 pode ser encontrado na pasta [Esp32](./Esp32/Esp32.ino). Nele, estão implementadas as funções de manipulação do banco de dados Firebase e o controle dos componentes conectados à placa.

No início do arquivo `.ino`, há campos com placeholders como `"xxxxxxxxxx"`, que devem ser substituídos pelo usuário com as informações corretas (nome da rede Wi-Fi e senha). Esses dados são necessários para que a placa se conecte à internet e possa interagir com o serviço de controle em nuvem.
